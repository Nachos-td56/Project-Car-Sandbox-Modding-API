Mod Loader Docs

Write Lua mods for Project Car Sandbox, Pack them as .pjcsm files, drop them in the Mods folder, and enjoy.

Overview

Mods are packaged as Unity AssetBundles using the .pjcsm extension. Each mod bundle must include a entry point script, aka a TextAsset explicitly named init. Upon launching the game, the loader automatically scans the mods directory, loads all available bundles, and executes their respective init scripts.

What you can do

  • Interact with Unity core objects, physics, rendering, and UGUI
  • Load textures, audio clips, and other scripts across bundles
  • Instantiate prefabs, control object lifecycles, and manipulate transforms
  • Bind UI buttons, toggles, and sliders cleanly
  • Register per-frame update hooks and non-blocking timers

What you cant do/is restricted

  • Direct disk I/O (File and Directory operations) is blocked for security
  • Unrestricted system commands or process launching is blocked
  • Only whitelisted C# and Unity types are accessible from Lua

Mod Structure

A compiled .pjcsm file is a standard Unity AssetBundle. At minimum, it requires:

mycoolmod.pjcsm
└── init         ← TextAsset containing your Lua entry script

You can bundle additional assets and other code files together:

mycoolmod.pjcsm
├── init         ← Required entry script, think of it like linux's init
├── mytexture    ← Texture2D asset
├── mysound      ← AudioClip asset
└── utils        ← Lua script that can be loaded via require()
Calling require("utils") automatically searches across all currently loaded mod bundles for a matching TextAsset.

Installing Mods

Place your .pjcsm mod file(s) directly into the Mods directory corresponding to your platform:

PlatformMods Folder Path
WindowsMods\ located right next to the game executable
Android/storage/emulated/0/Android/data/com.AKNDO.PJCS/files/Mods/
(Note: You may need an external file explorer app to access this path due to Android storage permissions)

If the Mods directory does not yet exist, simply launch the game once and the game will create it automatically.

Quickstart

Here is a minimal init.lua template to verify your setup:

print("[MyMod] Hello from Project Car Sandbox!") -- the [MyMod] tag isnt needed, but its better for workflow

local canvas = CS.ModHelper.FindGameObject("Canvas")
if canvas then
    print("Successfully found canvas: " .. canvas.name)
end

Save your script as a TextAsset named init inside a Unity AssetBundle project, package it with the .pjcsm extension, drop it into your Mods folder, and start the game.

ModHelper API

The helper exposed to the environment is CS.ModHelper, providing control over execution states, and utility hooks.

LoadModBundle

bool LoadModBundle(string modBundleFileName)

Loads a specific .pjcsm bundle from theMods directory into memory by filename. Returns true upon successful loading or if it is already active.

CS.ModHelper.Instance:LoadModBundle("expansion.pjcsm")

LoadAndRunAllMods

void LoadAndRunAllMods()

Scans the Mods folder, loads all discovered *.pjcsm files, and runs their init entry scripts. This is handled automatically during startup and should not be used unless necessary.

UnloadModBundle

void UnloadModBundle(string modBundleFileName)

Unloads a target mod bundle from memory and disposes of its associated assets. Any references pointing to assets inside this bundle will become invalid.

Asset Management Lua

GetModTexture

static Texture2D GetModTexture(string assetName)

Searches across all loaded mod bundles to retrieve a Texture2D asset by name.

local tex = CS.ModHelper.GetModTexture("custom_banner")
if tex then
    rawImage.texture = tex
end

GetModAudio

static AudioClip GetModAudio(string assetName)

Searches across all loaded mod bundles to retrieve an AudioClip asset by name.

local clip = CS.ModHelper.GetModAudio("custom_sound")
if clip then
    CS.ModHelper.PlayAudio(audioSource, clip)
end

Wait (Timers & Coroutines)

static void Wait(float seconds, LuaFunction callback)

Executes a deferred callback function after a specified delay time in seconds without blocking the main thread.

CS.ModHelper.Wait(3.5, function()
    print("3.5 seconds have passed!")
end)

Audio Helpers API

Convenience methods for managing audio playback safely across platforms:

PlayAudio

static void PlayAudio(AudioSource source, AudioClip clip)

Assigns a clip to an AudioSource and starts playback immediately.

PlayOneShot

static void PlayOneShot(AudioSource source, AudioClip clip, float volumeScale = 1f)

Plays a single audio clip pass-through at an optional volume scaling factor.

StopAudio

static void StopAudio(AudioSource source)

Stops playback on the specified AudioSource component.

SetAudioParams

static void SetAudioParams(AudioSource source, float volume, float pitch)

Adjusts both volume and pitch parameters on an AudioSource simultaneously in a single call.

Transforms & Prefabs API

Simplify object creation, destruction, and world adjustments directly from Lua:

  • CS.ModHelper.Instantiate(prefab) — Clones a target GameObject prefab.
  • CS.ModHelper.InstantiateAt(prefab, position, rotation) — Clones a prefab at specific world coordinates and orientation.
  • CS.ModHelper.InstantiateAsChild(prefab, parentTransform) — Instantiates a prefab directly under a designated parent transform.
  • CS.ModHelper.Destroy(go) — Safely destroys a target GameObject.
  • CS.ModHelper.DestroyDelayed(go, delay) — Destroys a GameObject after a specified time delay.
  • CS.ModHelper.SetActive(go, active) — Toggles the active state of a GameObject.
  • CS.ModHelper.SetLocalPosition(transform, x, y, z) — Sets local space coordinates.
  • CS.ModHelper.SetPosition(transform, x, y, z) — Sets world space coordinates.
  • CS.ModHelper.SetLocalScale(transform, x, y, z) — Sets local scaling vectors.
  • CS.ModHelper.LookAt(transform, worldPosition) — Rotates a transform to face a target world position.
  • CS.ModHelper.SetParent(childTransform, parentTransform, worldPositionStays) — Reparents a transform hierarchy.

UI Bindings & Component Shortcuts Lua

Quick lookup shortcuts to streamline component handling without complex type binding:

  • CS.ModHelper.GetComponent(go, "TypeName") — Fetches a component by string name.
  • CS.ModHelper.AddComponent(go, "TypeName") — Adds a component by string name.
  • CS.ModHelper.GetOrAddComponent(go, "TypeName") — Retrieves an existing component or adds one if missing.
  • CS.ModHelper.CreateGameObject(name) — Creates a new empty GameObject.
  • CS.ModHelper.SetTMPText(tmpTextComponent, text) — Sets text on TextMeshPro components safely.
  • CS.ModHelper.SetUIText(uiTextComponent, text) — Sets text on classic UGUI text components.
  • CS.ModHelper.SetImageSprite(imageComponent, sprite) — Assigns a sprite to a UI Image.
  • CS.ModHelper.SetImageColor(imageComponent, r, g, b, a) — Adjusts UI Image tint colors.

Button, Toggle, and Slider Listeners

Clean helper functions for wiring UI event callbacks:

-- Button Click Listener
CS.ModHelper.AddButtonListener(myButton, function()
    print("Button was clicked!")
end)

-- Toggle Value Listener
CS.ModHelper.AddToggleListener(myToggle, function(isOn)
    print("Toggle state changed: " .. tostring(isOn))
end)

-- Slider Value Listener
CS.ModHelper.AddSliderListener(mySlider, function(val)
    print("Slider value updated: " .. val)
end)

Update & Event Listeners API

Register custom per-frame loops using AddUpdateListener and safely clean them up when unloading via RemoveUpdateListener.

local myUpdateCallback = nil
myUpdateCallback = function()
    -- Runs every frame
end

-- Register to the main update ticker
CS.ModHelper.AddUpdateListener(myUpdateCallback)

-- To unregister later:
-- CS.ModHelper.RemoveUpdateListener(myUpdateCallback)

FindGameObject

static GameObject FindGameObject(string goName)

Finds any target GameObject by name across the scene graph, including hidden or inactive objects.

local uiObject = CS.ModHelper.FindGameObject("MainUI") 
    or CS.ModHelper.FindGameObject("Canvas")

Example — Text Toggle Mod

A functional example mod demonstrating how to locate existing UI elements, build custom overlay panels, bind click listeners, and handle keyboard input via per-frame updates.

-- ============================================================
-- Basic Text Toggle Mod (Free to be modified and or used)
-- ============================================================
local CS = CS
local UnityEngine = CS.UnityEngine
local UI = CS.UnityEngine.UI
local TMPro = CS.TMPro
local ModHelper = CS.ModHelper
local Keyboard = CS.UnityEngine.InputSystem.Keyboard

local originalText = "NOTE: UI IS NOT FINISHED"
local moddedText   = "Modded Menu"
local usingModded  = true
local menuVisible  = false
local noteTMP = nil
local menuRoot = nil

local function find(name)
    return ModHelper.FindGameObject(name)
end

local function makeUI(name, parent)
    local go = UnityEngine.GameObject(name, typeof(UnityEngine.RectTransform))
    if parent then
        go.transform:SetParent(parent.transform, false)
    end
    return go, go:GetComponent(typeof(UnityEngine.RectTransform))
end

local function addImage(go, color)
    local img = go:AddComponent(typeof(UI.Image))
    if color then img.color = color end
    return img
end

local function addTMP(go, text, size)
    local tmp = go:AddComponent(typeof(TMPro.TextMeshProUGUI))
    tmp.text = text or ""
    tmp.fontSize = size or 22
    tmp.alignment = TMPro.TextAlignmentOptions.Center
    tmp.color = UnityEngine.Color.white
    return tmp
end

local function setSize(rt, w, h)
    rt.sizeDelta = UnityEngine.Vector2(w, h)
end

local function setPos(rt, x, y)
    rt.anchoredPosition = UnityEngine.Vector2(x, y)
end

local function stretchFull(rt)
    rt.anchorMin = UnityEngine.Vector2(0, 0)
    rt.anchorMax = UnityEngine.Vector2(1, 1)
    rt.offsetMin = UnityEngine.Vector2.zero
    rt.offsetMax = UnityEngine.Vector2.zero
    rt.localScale = UnityEngine.Vector3.one
end

local function ApplyText()
    if not noteTMP then return end
    noteTMP.text = usingModded and moddedText or originalText
    ModHelper.Log("Text set to: " .. noteTMP.text)
end

local function BuildMenu()
    local hostCanvas = find("MainUI") or find("UtilUI") or find("cube") or find("Canvas")
    if not hostCanvas then
        ModHelper.LogWarning("No Overlay canvas found – aborting menu build")
        return
    end

    local root, rootRT = makeUI("TextToggleMenuRoot", hostCanvas)
    stretchFull(rootRT)

    local panel, pRT = makeUI("Panel", root)
    pRT.anchorMin = UnityEngine.Vector2(0.5, 0.5)
    pRT.anchorMax = UnityEngine.Vector2(0.5, 0.5)
    pRT.pivot = UnityEngine.Vector2(0.5, 0.5)
    setSize(pRT, 420, 220)
    setPos(pRT, 0, 0)
    addImage(panel, UnityEngine.Color(0.08, 0.08, 0.12, 0.95))

    local titleGO, tRT = makeUI("Title", panel)
    addTMP(titleGO, "Text Toggle Menu", 26)
    setSize(tRT, 380, 40)
    setPos(tRT, 0, 70)

    local statusGO, sRT = makeUI("Status", panel)
    local status = addTMP(statusGO, "Currently: Modded", 18)
    setSize(sRT, 380, 30)
    setPos(sRT, 0, 25)

    local btnGO, bRT = makeUI("ToggleBtn", panel)
    setSize(bRT, 280, 55)
    setPos(bRT, 0, -40)
    addImage(btnGO, UnityEngine.Color(0.25, 0.45, 0.7, 1))
    local btn = btnGO:AddComponent(typeof(UI.Button))

    local labelGO, lRT = makeUI("Label", btnGO)
    addTMP(labelGO, "Switch Text", 22)
    stretchFull(lRT)

    ModHelper.AddButtonListener(btn, function()
        usingModded = not usingModded
        ApplyText()
        status.text = usingModded and "Currently: Modded" or "Currently: Original"
    end)

    local hintGO, hRT = makeUI("Hint", panel)
    addTMP(hintGO, "Press F8 to hide/show this menu", 14)
    setSize(hRT, 380, 25)
    setPos(hRT, 0, -90)

    menuRoot = root
    menuRoot:SetActive(false)
end

-- Update listener callback
local function Update()
    local kb = Keyboard.current
    if kb ~= nil and kb.f8Key.wasPressedThisFrame then
        menuVisible = not menuVisible
        if menuRoot then
            menuRoot:SetActive(menuVisible)
        end
    end
end

-- Entry point execution
local noteGO = find("uinotfinished")
if noteGO then
    noteTMP = noteGO:GetComponent(typeof(TMPro.TextMeshProUGUI))
    if noteTMP then ApplyText() end
end

BuildMenu()
ModHelper.AddUpdateListener(Update)
ModHelper.Log("TextToggleMod ready, F8 to toggle menu")

Common Patterns

Safely Fetch Components

local go = CS.ModHelper.FindGameObject("SomeObject")
if go then
    local tmp = go:GetComponent(typeof(TMPro.TextMeshProUGUI))
    if tmp then
        tmp.text = "Updated text value"
    end
end

Check Input System Keys

local kb = CS.UnityEngine.InputSystem.Keyboard.current
if kb and kb.f8Key.wasPressedThisFrame then
    -- Execute action on keypress
end

Require External Scripts

-- Requires a TextAsset named "utils" bundled inside your/a mod
local utils = require("utils")
utils.doSomething()
